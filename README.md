# databricks_etl
Data Engineering with Databricks

## Realtime PySpark Scenarios

The `realtime_pyspark_scenarios/` folder contains production-style Structured Streaming examples for Databricks:

- Kafka clickstream events to bronze, silver, and gold Delta tables.
- Kafka IoT telemetry events with event-time watermarking and anomaly detection.
- Kafka payment transactions with realtime fraud-risk aggregation.
- Modular refactoring using shared config, readers, writers, and transformations.

Start with `realtime_pyspark_scenarios/README.md`.
